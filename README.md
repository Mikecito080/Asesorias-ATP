# ASESORÍAS ATP — Landing page (HTML/CSS/JS, sin dependencias)
**Ejecutar:** abre `index.html` o usa `npx serve .` / `python3 -m http.server`. **Desplegar:** sube la carpeta a Vercel, Netlify o hosting (sin build).
**Dónde cambiar:**
- Logo: texto en `.logo` dentro de `index.html` (header y footer).
- Colores: variables en `:root` de `styles/main.css`.
- Textos: directamente en `index.html` (FAQ y JSON-LD incluidos).
- Imagen hero: `assets/hero.svg` (reemplazable por .webp optimizado).
- Logos del banner: reemplaza `assets/logos/placeholder.svg` por `src` de cada logo oficial en los `<img>` de `.logos`.
- WhatsApp: busca `573115615958` (y `311 561 5958`) en `index.html`.
- Dominio: reemplaza `https://www.asesoriasatp.com/` en canonical, OG, JSON-LD, `robots.txt` y `sitemap.xml`.
